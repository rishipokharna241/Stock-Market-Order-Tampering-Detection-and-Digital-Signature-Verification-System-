Order verification

A clear path from order to verification

  1. 01

    Create

    Enter a buy or sell order record with a stock symbol, quantity, and price.

  2. 02

    Sign

    The browser signs a consistent version of the order using RSA-PSS and SHA-256; the backend checks it before saving.

  3. 03

    Verify

    The backend checks the signature later. Changing signed order details makes verification fail.
